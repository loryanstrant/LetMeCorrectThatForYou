# Let me correct that for you!

A polite public service for those moments when a product name, spelling, capitalisation, or bit of terminology is almost right.

Browse the correction directory, find the correct term, and share its direct link with whoever needs a small and helpful nudge. Common incorrect versions are preserved exactly as people write them—because the difference is often the entire point.

## Suggest a correction

The old website form has retired. You can now:

- [Suggest a correction with a GitHub issue](https://github.com/loryanstrant/LetMeCorrectThatForYou/issues/new?template=suggest-a-correction.yml)—no coding required.
- [Submit a pull request](CONTRIBUTING.md) if you would like to add or improve an entry directly.
